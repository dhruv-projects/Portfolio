# Shah Dhruv | Portfolio Website

Personal portfolio of Shah Dhruv, a second-year B.Tech Computer Science Engineering student at Uka Tarsadia University, Gujarat.

## Features
- Dark (night) theme with a clean, minimal layout
- Fully responsive: works on mobile, tablet and desktop
- Sections: Home, About, Skills, Projects, Experience and education, Contact
- **View résumé** and **Download résumé** buttons
- Built with plain HTML, CSS and JavaScript (no frameworks, no build step)

## Projects shown
- [Expense Tracker with Charts](https://github.com/dhruv-projects/Expense-Tracker-with-Charts)
- [Bank Account Management System (C)](https://github.com/dhruv-projects/Bank-manager)

## Project structure
```
index.html     page structure and content
style.css      all styling and responsive rules
script.js      mobile menu and active-link highlight
resume.pdf     résumé used by the buttons
assets/        profile.jpg, expense-tracker.jpg
```

## Run locally
Keep all files and the `assets` folder together, then open `index.html` in a browser.

## Deploy with GitHub Pages
1. Push all files to a repository.
2. Go to Settings, then Pages.
3. Select the `main` branch and the root folder, then save.
